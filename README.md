# AI-trip-planner-and-Hotel-booking-Management-

**Description:**
An AI-powered trip planner and hotel booking system that leverages the Google Gemini API to generate personalized travel itineraries. Built using Python, Django, HTML, CSS, JavaScript, jQuery, and Bootstrap, this intelligent assistant customizes trips based on user input such as location, duration, mood, and group type (solo, friends, couple, family).

**Technologies Used:**
Frontend: HTML, CSS, JavaScript, jQuery, Bootstrap
Backend: Python, Django
Database: SQLite
API: Google Gemini API

**Detailed Features:**
AI-powered trip planning using Google Gemini API
Customizable itineraries based on travel duration and destination
Personalized recommendations based on mood and group type
Interactive UI built with Bootstrap and jQuery
Responsive design for both desktop and mobile
User authentication system for personalized suggestions
SQLite database to store user preferences and trip history
Dynamic trip visualization and activity suggestions

**Applications:**
Automated travel planning for individuals and groups
Mood-based and preference-driven itinerary recommendations
Efficient travel management for busy users
AI-generated highlights of must-visit attractions and activities

**How It Works:**
Users input their travel destination, trip duration, and preferences. The system processes this information using the Google Gemini API to generate a tailored itinerary that includes attractions, activities, and optimal travel routes. Users can further customize their itinerary before finalizing their travel plan.
