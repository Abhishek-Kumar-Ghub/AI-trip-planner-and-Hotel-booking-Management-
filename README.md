# AI-trip-planner-and-Hotel-booking-Management-

**📝 Description:**
An AI-powered trip planner and hotel booking system that leverages the 🤖 Google Gemini API to generate personalized travel itineraries. Built using Python 🐍, Django 🌐, HTML 📝, CSS 🎨, JavaScript ⚙️, jQuery 💡, and Bootstrap 🎯, this intelligent assistant customizes trips based on user input such as location 📍, duration ⏳, mood 😊, and group type 👥 (solo, friends, couple, or family).

**🛠️ Technologies Used:**
Frontend: HTML 📝, CSS 🎨, JavaScript ⚙️, jQuery 💡, Bootstrap 🎯
Backend: Python 🐍, Django 🌐
Database: SQLite 🗃️
API Integration: Google Gemini API 🤖

**🚀 Key Features:**
🤖 AI-powered trip planning using Google Gemini API
📅 Customizable itineraries based on destination and duration
😊 Personalized suggestions based on mood and group type
💻 Interactive and responsive UI using Bootstrap and jQuery
🔐 Secure user authentication for personalized experiences
🗃️ SQLite database to store preferences and trip history
🗺️ Dynamic trip visualization and activity highlights

**🌍 Applications:**
👤 Automated travel planning for individuals, couples, families, and groups
😎 Mood-based and preference-driven itinerary recommendations
⏱️ Time-efficient trip management for busy travelers
🧭 AI-driven discovery of must-visit places and fun activities

**⚙️ How It Works:**
Users input their destination 📍, duration ⏳, and preferences 📝. The system processes this information using the Google Gemini API 🤖 to generate a tailored itinerary 🗺️ featuring attractions 🏰, activities 🎢, and optimized routes 🚗. Users can customize the plan before finalizing their travel schedule ✍️.
